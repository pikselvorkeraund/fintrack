
# FinTrack — ваши финансы, на вашем устройстве, под вашим контролем

**FinTrack** — полностью офлайн приложение для учёта личных финансов на Android.
Никакого облака, аккаунтов, рекламы и телеметрии — ваша денежная история живёт
только на телефоне и защищена шифрованием военного уровня.

🇬🇧 **[English version](../README.md)** · 🛠 **[Гайд для разработчиков](DEVELOPMENT.md)**

## Почему FinTrack

### 🔐 Безопасность, которую можно проверить
- **Зашифрованная база данных AES-256** (Room + SQLCipher). Ключ шифрования
  выводится из вашего **графического узора** через PBKDF2 (SHA-256, 120 000
  итераций) — узор *и есть* ключ. Без него файл базы физически нечитаем,
  даже с root-доступом или из образа диска.
- **Авто-вайп**: 3 неверных узора — ключ, соль и файл базы уничтожаются.
  Злоумышленник не получит ничего, никогда.
- **Разрешение INTERNET отсутствует в принципе.** Приложение не может отправить
  ваши данные никуда — это гарантирует манифест Android, а не «политика
  конфиденциальности».
- Системное резервное копирование отключено: финансы не покидают устройство
  незаметно для вас.

### 💶 Все валюты, которыми вы реально пользуетесь
RUB, USD, EUR, CNY, TRY, EGP, AED, THB, PHP, VND, BYN — **11 валют** с родными
символами. Переключение мгновенное: история, итоги и статистика всегда
отфильтрованы по активной валюте.

### 👥 Несколько счетов, настоящие категории
- Ведите отдельные книги: личную, семейную, рабочую — любое количество
  **счетов** с цветовыми идентификаторами.
- Встроенный набор категорий плюс свои собственные — каждая со стабильным
  цветом на графиках.

### 📊 Статистика, которая никогда не тормозит
- **Инкрементальные итоги**: каждая сумма (день / неделя / месяц / год / всё
  время) обновляется дельтой при каждом добавлении/удалении — никаких полных
  сканов таблицы, никогда.
- **Экран «Периоды»**: бар-чарты по категориям за любой период и вкладка
  **«Операции»** — полный список транзакций этого периода с ленивой
  подгрузкой по 20 записей (keyset-пагинация).
- История в тысячи записей открывается так же быстро, как в десять.

### 💾 Ваши данные переносимы — и по-прежнему приватны
- **Зашифрованный экспорт/импорт резервных копий**: вся база в одном файле
  `.fintx`, защищённом **вашим паролем** через PBKDF2 (310 000 итераций) +
  AES-256-GCM. Восстановление на любом устройстве — ключ копии независим от
  узора блокировки.
  Импорт в двух режимах: **полная замена** или **объединение** (дубликаты
  определяются автоматически).
- **CSV для Excel**: история счёта с разделителем `;`, десятичной запятой и
  UTF-8 BOM — открывается двойным кликом в Excel/LibreOffice/1С, локализованные
  заголовки, итоги по каждой валюте.

### ✨ Спроектировано, а не просто сделано
- Jetpack Compose, **Material 3**, тёмная и светлая темы.
- Полная **русская и английская локализация** — каждая строка в обоих языках.
- Сворачиваемая карточка баланса, компактные виджеты периодов, календарь и
  выбор времени для «задним числом» и планирования, безопасные подтверждения
  удаления.

## Где взять приложение

FinTrack собирается и подписывается через **GitHub Actions** — свежий APK лежит
в артефактах [вкладки Actions](https://github.com/pikselvorkeraund/fintrack/actions)
этого репозитория. Настройки сборки и подписи описаны в
[гайде для разработчиков](DEVELOPMENT.md).
